# wordpress-landing-page

SAAQi Tech - High-converting WordPress Winter Sale landing page with integrated Obsidian Luxe dark glass Admin Portal, dynamic SQLite lead capture, and Hostinger SMTP inquiry routing.

## Features
- **Winter Sale Landing Page**: 3 core WordPress packages (WordPress Website, Custom WordPress, WordPress + AI), 3D rendered badges, and responsive portfolio showcase.
- **Admin Portal (`/admin`)**: Obsidian Luxe dark glass dashboard with real-time lead analytics, SQLite database, multiple recipient routing settings, CSRF protection, and WAF security layers.
- **Dynamic Routing**: Automatically adapts to any domain, subdomain, or subdirectory without hardcoded URLs.
